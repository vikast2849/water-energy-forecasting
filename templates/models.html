Evaluation of 3 Core Algorithms (SVM, KNN, Logistic Regression)

In accordance with the project guidelines (Dept. of CS&E, SJMIT Chitradurga), three distinct machine learning algorithms are implemented and rigorously cross-validated using 5-Fold Cross Validation. Each algorithm fulfills specific functional roles: SVM provides high-dimensional non-linear mapping, KNN models community-specific localized demand, and Logistic Regression delivers calibrated probabilistic risk classification with full coefficient interpretability.

Architectural Synthesis & Model Roles

Criterion Support Vector Machine (SVM) K-Nearest Neighbors (KNN) Logistic Regression
Target Domain High-dimensional urban energy/water demand Localized community-specific rural demand Probability-based scarcity risk classification
Non-Linearity Handling High (via RBF kernel mapping) High (via instance distance weights) Moderate (via Sigmoid boundary)
Interpretability Low (Black-box kernel space) Moderate (Transparent nearest neighbors) High (Direct Log-Odds & Coefficients)
Inference Latency Fast (~2 ms per query) Moderate (Scales with dataset size) Ultra-Fast (< 1 ms per query)
